# Java GUI Programming

This folder contains Java GUI programs created while learning **Graphical User Interface (GUI) programming** using **AWT** and **Swing**.

The programs are arranged in a learning sequence, where each new program introduces a new GUI concept.

## Programs

| Program | Concept Learned |
|---|---|
| `GUI1.java` | Creating a basic AWT `Frame` |
| `GUI2.java` | Creating a basic Swing `JFrame` |
| `GUI3.java` | Closing a `JFrame` using `EXIT_ON_CLOSE` |
| `GUI4.java` | Adding a `JButton` to a `JFrame` |
| `GUI5.java` | Handling button clicks using `ActionListener` |
| `GUI6.java` | Displaying a message using `JOptionPane` |

## Technologies Used

- Java
- AWT (Abstract Window Toolkit)
- Swing
- Event Handling

## Learning Approach

Each program is created as a separate file to understand and practice a new GUI concept step by step.

As I learn new GUI concepts, I will continue adding new programs to this folder and update this README.
