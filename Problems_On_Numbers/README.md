# Java Number Problems

This folder contains Java programs based on **number-related problems and operations**.

The programs are created to practice and improve problem-solving skills, programming logic, loops, conditions, methods, and basic Java concepts.

## Topics Covered

- Prime Number
- Factorial
- Factors of a Number
- Perfect Number
- Armstrong Number
- Palindrome Number
- Even and Odd Number
- Digit Operations
- Reverse of a Number
- Sum of Digits
- Counting Digits
- Multiplication and Division Operations
- Other Number-Based Problems

## Learning Approach

The programs are organized progressively, where newer programs may build upon the logic used in previous programs.

The main focus is on:

- Understanding programming logic
- Using `if-else` conditions
- Using `for` and `while` loops
- Creating and calling methods
- Using `return` values
- Working with boolean flags
- Improving problem-solving techniques
- Writing clean and understandable Java code

## Technologies

- **Language:** Java
- **Input:** `Scanner`
- **IDE/Editor:** VS Code

This folder is part of my Java programming practice and documents my progress in solving different number-based problems.
