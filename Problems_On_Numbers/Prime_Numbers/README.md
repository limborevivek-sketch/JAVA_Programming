# Java Prime Number Programs

This folder contains Java programs based on **Prime Numbers** and different operations performed on prime numbers.

## About Prime Numbers

A **prime number** is a positive integer greater than `1` that has exactly two factors:

- `1`
- The number itself

Examples: `2, 3, 5, 7, 11, 13, 17...`



## Programs Covered

- Check whether a number is Prime
- Check Prime Number using factors
- Check Prime Number using `break`
- Check Prime Number using a Boolean flag
- Print Prime Numbers
- Count Prime Numbers
- Sum of Prime Numbers
- Find Prime Numbers within a given range
- Other Prime Number based problems

## Example Logic

The basic approach used in these programs is to check whether the given number is divisible by any number between `2` and `number / 2`.

If a divisor is found, the number is **not prime**.

If no divisor is found, the number is **prime**.
